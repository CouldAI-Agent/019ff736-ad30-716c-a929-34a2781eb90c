# Maintenance Tracker

A professional Flutter application for tracking recurring maintenance issues across different areas of a facility, such as Rooms, Outside Sitting Areas, and the Kitchen. It provides an easy-to-use checklist interface replacing traditional spreadsheet-based tracking.

## Features

- **Rooms Maintenance:** Track items like shampoo bottle brackets, Muslim shower leakage, door lock cylinders, washroom flush, exhaust fans, paint touch-ups, and washbasin stand paint.
- **Outside Sitting Areas:** Manage bulbs, holders, wires, generator service, and generator oil change.
- **Kitchen:** Track stove cleaning, aprons, knife sharpening, dusters, chef hairnets, and surf (detergent).
- **Tabbed Interface:** Easily switch between different areas using bottom navigation.
- **Interactive Checklists:** Tap to toggle the completion status of each maintenance item.

## Tech Stack

- Flutter (Cross-platform support for iOS, Android, Web, and Desktop)
- Dart

## Setup

1. Ensure you have Flutter installed.
2. Clone this repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to start the app.
